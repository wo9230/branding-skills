# Open Source Scope

## Included

- Three reusable Branding Skills and their generic references and templates.
- A project initializer that creates an isolated brand workspace.
- A runnable demo built only from synthetic data.
- Dependency-free validation and release-boundary checks.
- Public architecture, privacy, contribution, and security documentation.

## Not included

- Brand-specific records or generated deliverables.
- Personal, customer, transaction, communication, or operational data.
- Production integrations, private adapters, or real configuration values.
- Internal decision records and unpublished research material.
- Source repository history.

The repository is self-contained and does not require access to another project.
