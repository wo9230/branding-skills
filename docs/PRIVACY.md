# Safe Input Guidelines

Use the minimum material needed for the branding task.

## Do not add

- Authentication material or real configuration values.
- Private contact records or complete conversations.
- Orders, financial records, account exports, or backend screenshots.
- Unlicensed images, fonts, documents, or testimonials.
- Local absolute paths that reveal a workstation identity.

## Examples

Examples must be synthetic, visibly marked as fictional, and unable to identify a real person or organization.

## Brand projects

Keep each real brand in a separate project directory. Do not store real brand projects inside the installed Skill directories or this repository.
