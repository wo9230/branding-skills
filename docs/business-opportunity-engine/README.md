# Business Opportunity Engine

> 本目录定义品牌创建之前的商业机会发现、研究、筛选和验证方法。它是现有 Branding Skills 的上游研究层，不替代现有品牌访谈与品牌档案治理。

## 核心目标

把“发现值得做的生意”变成可重复、可审计、可持续迭代的流程：

1. 发现行业变化和需求信号。
2. 研究龙头企业、财报、产品线和产业生态。
3. 拆解主产品、配件、耗材、工具、维修、替换和服务。
4. 找到未被充分服务的细分需求，而不是把搜索不到误判成市场空白。
5. 验证中国供应链、质量、认证、知识产权和交付能力。
6. 测算渠道贡献利润、库存和现金流。
7. 通过小规模实验决定进入、调整或退出。
8. 只有通过机会门禁后，才进入现有 Branding Skills 创建品牌。

## 与现有项目的关系

现有项目继续负责：
- brand-journey：访谈、阶段推进、审批关卡。
- brand-foundation：事实、证据、决策和品牌定位的唯一事实源。
- brand-expression：品牌表达和渠道文案。
- brand-visual-board：视觉方向和品牌板。
- brand-handoff：向网站和其他 AI 交接品牌资料。

新增的商业机会研究层负责品牌成立之前的行业、产品、竞争、供应链和经济性判断。不要把未经验证的市场假设直接写成 BRAND.md 的已确认事实。

## 核心方法：生态切入，而非盲目仿制

研究龙头企业时，不只看它卖什么，还要研究它建立了什么生态：
- 核心设备和产品
- 安装与维修工具
- 配件、耗材和替换件
- 兼容件、升级件和改装件
- 检测、校准和维护服务
- 培训、技术资料和型号数据库
- 分销商、维修商、安装商和终端客户

机会通常出现在这些生态的边缘、长尾、服务断点或特定客户场景中。复制的是市场研究方法和商业逻辑，不是他人的商标、专利、外观设计、受保护文案或未经授权的产品资料。

## 重要边界

- “龙头没有展示”不等于“龙头放弃”。
- “Amazon 搜不到”不等于“没有需求”。
- “中国有工厂”不等于“具备目标市场合规能力”。
- “规格看起来相同”不等于“可安全互换”。
- “有流量”不等于“有贡献利润”。
- “供应商说能做”不等于样品和批次验证通过。
- “AI 研究结论”不等于真实订单或商业效果。

任何机会结论必须带来源、日期、证据等级、适用范围和待验证事项。
