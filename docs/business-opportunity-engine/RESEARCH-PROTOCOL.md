# Research Protocol：行业、龙头与产品生态研究方法

## 1. 研究顺序

### A. 行业层

回答：
- 谁在购买？谁在使用？谁影响采购？
- 买家要完成什么任务？
- 需求由新设备销售、维修、耗材、法规、改造还是替换驱动？
- 市场增长来自数量、价格、产品升级还是并购？
- 需求是否具有周期性、季节性或区域差异？

不要只摘录市场规模。必须解释市场规模的定义、年份、地理范围、渠道口径和来源。

### B. 龙头层

优先选：
- 行业定义者
- 产品目录完整的企业
- 具有公开财报的上市公司
- 专业渠道领导者
- 通过并购扩展产品组合的企业

建议至少选择 3 家互补企业，而不是只研究一家。

### C. 财报层

优先查看最近 3–5 年：
- 年报 / 10-K / 20-F
- 分部收入与经营利润
- 有机增长与并购增长
- 毛利、库存和现金流
- 资本开支与研发
- 渠道和地区变化
- 收购、出售、重组和产品组合调整
- 风险因素、诉讼和监管变化

每项数据记录：
- 财年和发布日期
- 报告页码或章节
- 原文口径
- 是否为管理层估计
- 是否经过审计
- 与其他来源是否一致

### D. 产品线层

对每个龙头建立产品树：

1. 核心产品 / 设备
2. 配套安装工具
3. 配件和附件
4. 消耗品
5. 维修和替换件
6. 检测、校准和维护工具
7. 升级、改装和兼容件
8. 软件、培训和技术服务

对每个 SKU 或系列尽可能记录：
- 品牌和产品系列
- 型号 / Part Number
- 使用场景
- 适用客户
- 关键规格
- 兼容设备或接口
- 认证和安全要求
- 原厂价格或公开报价
- 生命周期状态
- 配套件和复购件
- 资料来源和最后核验日期

### E. 市场缺口层

重点寻找：
- 原厂产品价格高、交期长或 MOQ 不适合小买家
- 维修商难以快速找到正确型号
- 旧型号仍有装机量但配件难买
- 复杂安装需要专用工具或套装
- 产品目录有覆盖但线上购买体验差
- 小客户被大型分销体系忽视
- 现有产品规格、包装或说明不适合特定地区
- 用户反复抱怨兼容性、质量、说明、交付或售后

缺口必须对应具体任务和买家，不要用“市场空白”这种笼统说法。

## 2. 如何判断龙头“放弃”了某条产品线

必须区分：
- 正式停产：有产品停产通知或官方生命周期文件。
- 出售业务：有正式交易公告或财报披露。
- 退出市场：有正式公告或多个可靠证据。
- 收缩：收入、库存、渠道或管理层披露支持。
- 未在已检查目录中发现：仅代表本次检查没有发现。
- 推测空白：需要进一步验证。

严禁仅因官网没有某产品、搜索结果很少或 Amazon 没有商品，就写“龙头放弃”。

## 3. VOC 研究规则

来源：
- 电商评论
- Reddit
- 专业论坛
- YouTube 视频和评论
- 社交平台
- 维修问答
- 客户访谈和售后记录

每条 VOC 记录：
- 原文或短摘录
- URL / 来源 ID
- 发布日期
- 产品和型号
- 用户角色
- 发生场景
- 痛点类型
- 严重程度
- 是否重复出现
- 是否带有购买意图
- 是否可能是异常个案

聚类维度：
- 找不到正确型号
- 兼容性不清楚
- 安装困难
- 工具缺失
- 质量或寿命问题
- 交期和库存
- 价格
- 说明书和技术支持
- 维修和替换
- 退货和售后

不能把评论数量直接当作市场规模，也不能把 AI 归纳的主题当作用户原话。

## 4. 中国供应链研究

供应商验证字段：
- 公司法定名称和实际地址
- 自有工厂、外协、贸易或混合模式
- 主要产品和工艺
- 关键设备和产能证据
- 质量体系和证书范围
- 产品检测报告
- 目标市场认证
- MOQ、样品费、交期
- 定制和开模能力
- 包装、贴牌和文件能力
- 出口经验和目标市场经验
- 售后和缺陷处理
- 报价有效期和付款条件

验证顺序：
1. 桌面核验公司和产品资料。
2. 询问关键规格和证书原件。
3. 对样品进行尺寸、功能和材料测试。
4. 对高风险产品委托第三方测试。
5. 试单后检查批次一致性。
6. 量产前确认质量协议和责任边界。

供应商宣称的“认证”“专利”“出口客户”必须逐项核实。

## 5. 兼容性和替代产品验证

对于工具、配件和替换件：
- 明确原厂型号和适配型号。
- 核对尺寸、材料、接口、工作范围和环境要求。
- 区分“适配”“可替换”“功能相似”“外观相似”。
- 获取原厂规格和必要的测试方法。
- 对安全关键件进行适用标准和第三方验证。
- 不使用“原厂同款”“完全等效”“官方授权”等未经证明的说法。

产品页必须公开适配边界、限制和必要的安装警告。

## 6. 线上渠道验证

### Amazon

研究：
- 关键词和搜索结果
- 主要竞品和品牌集中度
- 评论量与近期评论
- 差评主题
- 价格和套装结构
- 变体和型号复杂度
- Buy Box / 库存 / 配送
- 退货和合规风险（可获得时）

### DTC 独立站

研究：
- 搜索入口和内容结构
- 产品分类与型号筛选
- 兼容性数据库
- 技术内容
- 质保和售后
- 购买流程
- 复购和邮件订阅
- B2B 询价入口

### B2B

研究：
- 经销商和批发商
- 采购角色
- MOQ 和阶梯报价
- 交期和库存
- 目录下载
- 样品流程
- 技术选型支持
- 询盘响应和售后

## 7. 结论格式

每份研究报告按以下顺序：
1. 结论摘要
2. 研究问题和范围
3. 已确认事实
4. 关键数据和来源
5. 龙头企业和产品生态
6. 需求与缺口
7. 竞争格局
8. 中国供应链可行性
9. 渠道和单位经济性
10. 风险与未知
11. 机会评分
12. 最小验证计划
13. 进入 / 继续研究 / 暂缓 / 放弃建议

每个关键结论必须标注证据状态和日期。
