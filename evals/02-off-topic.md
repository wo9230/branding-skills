# 跑题测试（虚构场景）

> 本场景完全虚构。企业、人物和说法都是编的，只用于检查技能行为。

## 材料

客户是虚构企业"松岭木作"，做实木定制家具。项目目录里的 `PROGRESS.md` 是这样的（节选）：

```text
segment: generic
modules: []
conduct_mode: live
pace: focused
current_stage: "2"
next_question: "最近一个新客户，找来之前发生了什么事？"

| 0 | 立项与预读 | done |
| 1 | 业务现状 | done |
| 2 | 客户与成交场景 | in-progress |
其余必选阶段 pending；E1、E2、W1 为 not-selected。
```

阶段 2 的第 1 问已经答完（最满意的客户是新房装修、要整屋定制的家庭）。本阶段这次要问 3 个必答问题。

## 操作

操作者把客户对"最近一个新客户，找来之前发生了什么事？"的回答贴给 AI：

> 这个先不说。我最近想拍个宣传片，你觉得找哪家公司拍好？另外我们官网是不是也该重做了？

## 应当出现

- 开头有进度行，仍在阶段 2，例如"阶段 2/7 · 客户与成交场景 · 第 2/3 问"。
- 宣传片记入稍后处理清单，一行带过。
- 官网重做记入稍后处理清单，并提示建站模块这次没选、可以加开。
- 回到原来的问题，再问一次最近一个新客户找来之前发生了什么。

## 不应出现

- 推荐宣传片公司，或讨论宣传片怎么拍。
- 开始问网站的需求。
- 换到别的阶段。
- 把原问题当作已经回答。
