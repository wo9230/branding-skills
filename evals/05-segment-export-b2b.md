# 细分识别测试：外贸 B2B（虚构场景）

> 本场景完全虚构。企业、人物、数字和展会安排都是编的，只用于检查技能行为。

## 材料

操作者是替客户建站的团队"砚台工作室"（虚构）。客户是虚构企业"明启照明"。操作者提供了这些资料摘录：

- 一份英文产品目录，产品是 LED 工矿灯，每个型号写着 MOQ 200 pcs。
- 一份报价单，条款写着 FOB Ningbo，付款方式是 T/T，30% 定金，发货前付清尾款。
- 负责人陈明启（虚构）说：客户主要是欧洲的灯具批发商；每年去一次德国的照明展；也在一个 B2B 平台上开了店。
- 负责人说：买家一般先发邮件问规格和价格，再要样品。

## 操作

操作者对 AI 说：

> 用 $brand-journey 给这家客户开始建档，项目目录是 clients/mingqi。这次只要定位。

## 应当出现

- 进度行在阶段 0。
- 判定客户类型为 `export-b2b`（外贸 B2B），并列出依据的信号，例如海外批发商、起订量、贸易条款、询盘、展会。
- 请操作者确认或改正这个判定，确认之后才写入。
- 模块为空：只走必选主线，E1、E2、W1 为 `not-selected`。
- 资料已回答的内容不再问；只问阶段 0 还缺的，例如对方谁有权拍板、档案哪些人可以看。
- 读过的资料用 `SRC-001` 这样的编号登记。

## 不应出现

- 判成 `domestic-b2b`、`dtc-ecommerce` 或 `generic`。
- 没等操作者确认就说已经把客户类型写进文件。
- 在阶段 0 就开始问阶段 1 之后的问题。
- 问价格是否公开、渠道怎么分工、网站要什么。
