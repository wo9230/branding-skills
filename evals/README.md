# Evals

这里是用虚构材料写的行为场景，用来检查一个没看过任何讨论的 AI，只凭技能文件能不能做对。场景里的企业、人物、数字和对话都是编的，不对应任何真实对象。

这些场景不进 CI：仓库不依赖网络，也不调用任何模型。改了技能文件之后，由人或代理手动运行。

## 怎样运行一个场景

1. 开一个不带任何对话历史的新会话或新代理。
2. 只给它场景文件头 `skills:` 列出的技能文件夹。`skills: []` 表示什么技能都不给。
3. 把场景的"材料"和"操作"原样交给它。不要给"应当出现"和"不应出现"。
4. 拿它的回答逐条对照"应当出现"和"不应出现"。
5. 有一条不符就算不通过：改技能文件，再从第 1 步重跑。

## 场景文件格式

```markdown
---
eval: 03-skip-gate
fictional: true
skills: [brand-journey, brand-foundation]
spec_ref: "6.3 规则 10"
---

# 标题（虚构场景）

## 材料

## 操作

## 应当出现

## 不应出现
```

- `eval` 必须等于文件名（不含 `.md`）。
- 四个二级标题必须齐全，顺序固定。
- "应当出现"和"不应出现"写成可以逐条判断的短句。

## 新增一个场景

先把场景名加进 `tests/test_evals.py` 的 `EXPECTED_EVALS`，再写场景文件。测试会检查清单与文件一一对应、格式正确；`scripts/verify_release.py` 会检查每个场景都带虚构标注。
