# 产品、服务与渠道文案

## 先核对交易基础

文案开始前确认：真实供给、适配对象、交付方式、价格或价格状态、购买/申请路径、履约能力、退款或退出边界、可公开证明和不能承诺的结果。缺少这些内容时可写结构或候选，不得用强 CTA 掩盖。

高客单、高风险或高投入产品需要更长的解释、更多证明和更清楚的适配边界；低客单可以缩短路径，但不能制造虚假稀缺。

## Offer 信息顺序

按受众的决策顺序组合，不强制每个页面使用全部模块：

1. **标题**：对谁、解决什么可识别问题或形成什么能力；
2. **副标题**：通过什么方式，在什么条件下；
3. **当前处境**：描述真实卡点和失败尝试，不替受众编情绪；
4. **结果形态**：会留下什么能力、资产、流程或可验收产物；
5. **机制与过程**：为什么这种交付能解决问题；
6. **包含内容**：具体权益、节奏、边界和第三方成本；
7. **证明**：授权案例、过程证据、作品或可核验数据；
8. **适合/不适合**：降低错购和错误期待；
9. **风险与限制**：不能保证什么，结果受哪些条件影响；
10. **行动**：一个与当前信任程度匹配的主要 CTA。

可以使用“你会完成 / 你会学会 / 它替代什么”的成果结构，但每一句都必须对应真实交付，不能把学习机会写成必然掌握，把流程写成商业结果。

## 课程、会员和社群

- 课程：区分知识内容、实操、反馈、作业、验收和支持；
- 会员：写清期限、频率、缺席、补课、支持渠道和终止边界；
- 社群：写清加入后实际得到什么，不能只卖“高质量圈子”；
- 线上与线下：说明各自适配条件，不把低价产品故意写成残缺版本；
- 收益、流量、询盘和订单：只能作为范围明确的案例，不作为普遍保证。

## 渠道改写

保持同一核心命题，改变信息密度与下一步：

- 平台显示名：识别优先，不塞完整定位；
- 个人简介：身份、对象、价值和一个入口；
- 社交帖：从一个真实观察或动作进入，只推进一个判断；
- 公众号/长文：允许展开背景、机制、证据和限制；
- 落地页：按决策顺序处理疑虑与行动；
- 销售对话：先判断适配，再解释供给，不制造即时压力。

渠道适配不能偷偷改变受众、承诺、价格、权限或产品边界。需要改变时返回 foundation 做新决定。

## 网站页面文案

网站文案以 `BRAND.md` 里已经确认的品牌表述为依据：定位、主信息、支持点和声音方向。那几项还是候选时，页面文案也只能是候选，并在 Claim Map 里照实标注。

每一页按访客的决策顺序写，一页只推一个主要行动：

| 页面 | 访客带着什么问题来 | 主信息 | 证明 | 行动 |
|---|---|---|---|---|
| 首页 | 这家是做什么的，和我有没有关系 | 定位的一句话，加最强的一条支持点 | 一到两条可公开的证明 | 主转化动作 |
| 产品或服务页 | 它具体是什么，适不适合我 | 这一项解决什么事、怎么交付、适合谁和不适合谁 | 规格、流程、对应的证明 | 询价、下单或了解详情 |
| 关于 | 这家可不可信，是谁在做 | 真实的起源和原则，不编故事 | 团队、资质、可核对的经历 | 联系 |
| 案例与证明 | 别人用了怎么样 | 客户原来的问题、做了什么、对方认可的结果 | 授权的案例、数字、评价 | 看更多或联系 |
| 联系或询盘 | 我要怎么开始，要准备什么 | 下一步发生什么、多久有人回应 | 现行的回复时限 | 提交 |

规则：

- 页面上每句承重的文案，包括标题、主张、数字、承诺和行动按钮的条件，都在 Claim Map 登记一个 Copy ID。`SITE-BRIEF.md` 按 Copy ID 引用文案，不另写一份。
- 没有可公开证明的说法不上页面，或降成不带承诺的表述。
- 价格、交期、起订量、退换这类条款，一字不差地用 `BRAND.md` 里的现行规则；规则没定的不写。
- 页面类型和主转化动作以 `BRAND.md` 的 `DEC-SITE` 为准。没有这项决策时，只写候选文案，不替客户决定网站的任务。

访谈语言和网站语言不同时，先读 `BRAND.md` 文件头的 `segment` 和 `languages`。`segment: export-b2b` 是最常见的情况：访谈用中文，网站用英文或多语种。

1. 先用访谈语言把含义定下来，登记 Copy ID。
2. 再写目标语言稿，作为同一个 Copy ID 的另一种语言版本。
3. 翻译时不增加承诺，不把"力争"写成保证，不补原文没有的数字和形容词。
4. 单位、标准名称、证书名称和行业术语用目标市场通行的写法，证书名称照证书原文。
5. 目标语言稿仍要审批人确认；审批人看不懂时，由他指定的人确认，并在 Claim Map 记下确认人。
