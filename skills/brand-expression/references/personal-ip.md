# 个人与创始人 IP 表达分支

## 四个承重问题

个人 IP 的外部表达至少要回答：

1. **服务谁**：具体到阶段、处境和当前任务；
2. **提供什么持续价值**：一次看完能得到什么，持续关注或合作能积累什么；
3. **凭什么由这个人提供**：亲身经历、做事过程、判断、作品、案例或明确证据缺口；
4. **通向哪里**：连接哪个真实产品、服务、合作方式或长期用途。

身份是信任材料，不自动构成定位。不要只用职业、年龄、地域或“某领域专家”完成表达。

## 关系姿态与记忆

定义品牌和受众的关系，例如同行者、实践者、研究者、顾问或教练。关系必须由公开行为体现，不能只写在简介中。

可从以下类别选择一个当前主记忆资产，最多两个辅助：

- 身份：真实、相关且可证明的经历组合；
- 立场：在关键取舍上持续做出的判断；
- 语言：反复出现且自然的表达习惯；
- 视觉：稳定、可维护的识别方式；
- 行为：持续展示研究、实操、拆解、测试或服务过程。

候选记忆资产必须标为候选；只有真实内容反复出现后才能记为已观察资产。

## 内容支柱

每条支柱连接四项：

`一类受众问题 × 当下/持续价值 × 本人的证明方式 × 业务连接`

一条合格支柱应说明：它解决什么问题、观众得到什么、晓得为什么由这个人讲、可持续产生哪些题型、最终连接哪个行动。常用内容动作包括展示过程、讲真实故事、教具体方法和给有依据的判断；按品牌能力选择，不机械凑齐。

个人 IP 内容既可以整理外部项目，也可以分享亲身实践。整理别人项目时，个人价值来自选择标准、实际测试、适配判断、限制和业务用法，不来自把公开信息重新搬运一遍。

## 个人简介

简介不是履历清单。按触点选择长度：

- 极短：身份或视角 + 服务对象 + 稳定价值；
- 标准：再加入可信经历或方法；
- 完整：再加入当前产品、边界和行动。

未核验资历、客户结果和数字不能因为字数短就省略证据门禁。第一人称可以更亲近，但只能写本人已提供的经历和判断。

## 个人 IP 验证记录

将定位、简介、内容支柱或主张投入真实使用后，记录渠道、日期、原文、目标行为、结果和同时变化的因素。批准采用只表示选择；真实结果才能支持 `learning_status`。单次高表现不自动证明长期定位成立。
