# 事实、证据与决策协议

品牌档案同时保存现实、解释和选择。三者必须分开，否则一份漂亮报告会把推测洗成“品牌事实”。

## 三组独立状态

### 事实状态 `fact_status`

| 状态 | 含义 | 可否对外使用 |
|---|---|---|
| `verified` | 有可定位的原始记录或权威来源，且范围、日期匹配 | 仅在证据允许的范围内 |
| `user-stated` | 用户明确自述，但尚未由材料核验 | 可作内部输入；对外重要主张仍需证据 |
| `hypothesis` | 为推进工作提出的待验证解释 | 不得写成既有事实 |
| `unknown` | 当前不知道或用户选择跳过 | 不补造 |
| `conflicted` | 不同来源互相冲突 | 冲突解决前不放行依赖项 |
| `stale` | 曾经成立，但时间、版本或范围可能已失效 | 更新核验前不作为当前事实 |

### 决策状态 `decision_status`

| 状态 | 含义 |
|---|---|
| `candidate` | AI 或参与者提出，尚未批准 |
| `approved` | 有权限的 owner/approver 明确选择 |
| `rejected` | 已明确否决，保留原因以免反复提出 |
| `superseded` | 曾获批准，后被新版本替代 |

“确认这个方向”只能把 `candidate` 变为 `approved`。它不能把 `hypothesis` 变为 `verified`，也不能把没有发生的故事、结果或客户原话变成事实。

### 学习状态 `learning_status`（可选）

学习状态只用于记录一个定位、信息、内容支柱或表达假设经过现实使用后的结果，不替代事实或决策状态：

| 状态 | 含义 |
|---|---|
| `untested` | 已形成可执行假设，尚未收集结果 |
| `testing` | 已开始使用，但样本或时间不足 |
| `supported` | 在声明范围内得到重复、可定位证据支持 |
| `contradicted` | 现实结果与原假设冲突 |
| `retired` | owner 决定停止继续使用或验证 |

`approved` 只表示 owner 选择采用；不等于 `supported`。一次高表现、一次投诉或模型判断都不能自动升级为稳定规律。记录观察范围、日期、使用的表达、结果、同时变化的因素和下一次验证。

## 最小来源记录

每个会影响定位、承诺或公开文案的重要事实，应能追到：

- `source_id`：稳定编号；
- `source_type`：访谈、订单、合同、邮件、网页、报告、观察或用户自述；
- `location`：文件路径、URL 或记录位置；
- `source_date` 与 `checked_at`；
- `scope`：对应哪个品牌、市场、产品、型号、时期；
- `read_scope`：读了全文、节选、摘要还是标题；
- `permission`：`public`、`internal`、`restricted` 或 `unknown`。

不能公开的材料可以支持内部判断，但输出只记录脱敏结论和来源代号，不复述敏感原文。

## 高风险主张门禁

| 主张 | 放行前需要什么 |
|---|---|
| 客户原话、评价、案例 | 原始记录、主体与用途授权；回忆只能标为转述 |
| 收入、增长、节省、转化等数字 | 可定位数据、计算口径、时间范围 |
| 认证、测试、合规 | 具体标准、主体、产品/型号/配置、状态与日期 |
| 价格、交期、MOQ、退换、质保 | 当前有效规则及适用条件 |
| “更快、更好、领先”等比较 | 比较对象、指标、方法、日期及反证 |
| 能力与服务范围 | 实际交付记录或现行可执行流程；愿景不算能力 |
| 创始故事与个人经历 | 本人提供的真实事件；不得为叙事效果补情节 |
| 竞品与市场结论 | 实际来源与查询日期；官网只证明其公开表述 |

证据不足时仍可写完整的内部工作稿，但使用 `[候选]`、`[假设]`、`[待验证]` 或占位说明。不得用模糊数量、虚构示例或“行业通常如此”填空。

## 经营选择边界

以下属于 owner 决策：优先市场、受众取舍、Offer、价格、服务范围、公开承诺、渠道、频率、预算、指标、命名采用、品牌架构和明确不做的业务。

AI 可以给少量候选及各自代价。没有明确批准时：

- 不写入 `BRAND.md` 的已批准区；
- 不把候选继续推导成整套执行计划；
- 不因“今天急用”替用户拍板；
- 在报告里说明若采用该候选，哪些下游内容会改变。

任务明确要求经营落地时（例如 `$brand-journey` 的落地模块），记录 owner 对产品、价格、渠道、推广的决策属于基础工作，方法见 [strategy-and-execution.md](strategy-and-execution.md)。边界不变：每项最多三个候选并写清代价，由具名审批人拍板；现状写成事实，选择写成决策；仍不产出内容日历、投放计划或漏斗搭建，也不替 owner 定价格数字。

## 外部研究

涉及当前竞品、商标、域名、法律、认证、平台规则、价格或市场事实时，必须使用可用的实时研究能力，并优先原始/官方来源。记录查询日期和未覆盖范围。查不到就是 `unknown`；不得声称已核验。

## 私有状态与公共 Skill

真实品牌档案、客户材料、联系方式、账号、报价、后台截图和测试输出只放在用户明确指定的品牌项目目录。不得复制进已安装 Skill、公共示例、发行包或测试夹具。测试只能使用明确标注的合成资料。
