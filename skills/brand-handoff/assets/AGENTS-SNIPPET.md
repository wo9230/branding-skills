# 可粘贴片段：放进网站代码仓库

网站代码通常在另一个仓库。把下面"品牌档案"一节贴进那个仓库的 `AGENTS.md` 或 `CLAUDE.md`，并把 `brand/` 换成档案实际所在的位置。档案可以复制或链接到网站仓库的一个子目录；含内部信息的文件不要提交到公开仓库。

---

## 品牌档案

这个网站所属企业的品牌档案在 `brand/`。写任何页面内容、文案或设计之前：

1. 先读 `brand/COMPANY.md`，了解这家企业卖什么、卖给谁、凭什么、哪些话不能说。
2. 页面结构和每页内容按 `brand/SITE-BRIEF.md`；文案用 `brand/MESSAGING.md` 里对应编号的文案；视觉按 `brand/output/DESIGN.md`（存在时）。
3. 事实和决定以 `brand/BRAND.md` 为准。几份文件不一致，或派生文件文件头的 `foundation_version` 低于 `BRAND.md` 的 `version` 时，以它为准，并提醒使用者派生文件已过期。版本号按数字比较：`0.10` 高于 `0.9`。
4. 不新增承诺、数字、客户名称、评价或认证。`SITE-BRIEF.md` 里标为缺失的素材和"待表达"的文案，留空并标注，不要自己补。
5. 企业和品牌的名称、品类的叫法、对外的数字，照 `brand/MESSAGING.md` 的"标准说法"写（存在时）；页面之间不要各写各的。
6. 带 `[候选决策]`、`[假设]`、`[未知]` 标签的内容不上线。`SITE-BRIEF.md` 标着"概念，未批准"时，只做草稿，不发布。
