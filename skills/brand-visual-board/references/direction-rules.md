# 视觉方向规则

## 先建立战略对比

探索模式通常给 2–3 个方向。每个方向至少在以下四项上有实质差异：品牌姿态、视觉逻辑、字体角色、图像/构图语言、界面或包装行为、最适用的触点。只换色不算一个新方向。

方向名称应表达设计思想，避免只叫“现代、极简、高端、大胆”。名称不能替代说明。

每个方向写清：

- 它强化哪项已确认策略；
- 它如何解决受众、品类或触点中的张力；
- 色彩、字体、版式、图像、材质或动效分别承担什么角色；
- 最适合和最不适合的场景；
- 最大误读、实现成本和待验证点；
- 需要什么真实内容才能成立。

## 推荐规则

推荐一个方向时，以适配性为依据：

1. 是否忠实表达已经选择的定位和取舍；
2. 是否能在主要触点稳定执行；
3. 是否与真实产品、内容和资产兼容；
4. 是否避免最危险的误读；
5. 小团队是否有能力长期维护。

没有足够依据时可以并列保留，不制造“确定赢家”。记录批准人和批准范围；网站方向获批不自动批准包装或 Logo。

## 角色化设计

- 颜色：背景、正文、强调、状态、交互和数据角色；
- 字体：展示、正文、数据/技术、备用及各语言覆盖；
- 图像：主体、视角、光线、真实/概念、授权与禁用手法；
- 布局：层级、密度、节奏、栅格和不同屏幕行为；
- 组件：按钮、卡片、标签、表格、表单和信任证据；
- 动效：只在帮助理解状态、层级或反馈时使用。

不要因为某个“品牌原型”机械指定颜色或字体。参考品牌只能分析原则，不复制可识别的商标、插画、版式或包装组合。

## 质量检查

- 视觉板在 1440px 与约 390px 宽度无横向溢出，正文可读；
- 推荐方向一眼可辨，但其他方向仍能公平比较；
- 字体有 fallback，来源与许可状态有记录；
- 声称满足 WCAG 的文本组合有对比度结果和标准级别；
- 所有虚构内容在它出现的位置标为概念；
- 没有外部依赖时可离线打开；有依赖则明确列出；
- HTML 是展示板，不伪装成已经实现的网站或产品。
